### 1. `add-mouse-driven-orbit`
- **Purpose**: Add restrained mouse-driven orbit and parallax depth to a Three.js hero by damping one pointer target and splitting it across camera translation, look-at, and small object rotations. Use for passive cinematic 3D heroes, pointer-responsive scenes, organic model parallax, and interactive depth where OrbitControls would feel like a product viewer.
- **Produces**: Three.js, GLSL Shaders, CSS3
- **Dependencies**: assets/three.min.js
- **Works Offline**: **Yes** — Self-contained CSS/JS logic with zero external network requests.
- **Projector Performance Risk**: **High** — Continuous RAF WebGL/Canvas rendering loops risk GPU thermal throttling and frame drops on projector laptops.
- **Accessibility Notes**: Reduced motion: Explicit `@media (prefers-reduced-motion: reduce)` support; Contrast: Not specified; requires contrast check on dark surfaces; Keyboard: Preserves visible focus states
- **Bank Security Product Fit**: **fits with care** — Usable if palette is aligned with deep navy/electric teal and animations are kept to fast, subtle micro-interactions.

### 2. `add-shader-cursor-trail`
- **Purpose**: Add the Shaders WebGPU mouse effect used for the Tidal Commons hero: a white twinkling halftone cursor trail driven by ChromaFlow, masked through a DotGrid, finished with chromatic ripples and film grain, and protected by static, touch, accessibility, SSR, and performance fallbacks. Use when a user asks for this shader mouse effect, a halftone cursor trail, an interactive WebGPU hero/contact background, or a reusable cursor-following shader layer in React, Next.js, Vue, Svelte, Solid, or plain web projects.
- **Produces**: Three.js, GLSL Shaders, React / TSX, CSS3
- **Dependencies**: Three.js library via CDN (`unpkg.com/three`)
- **Works Offline**: **Yes (vendored) / No (default)** — Default demo references external CDNs, but script/font assets are bundled locally in the folder.
- **Projector Performance Risk**: **High** — Continuous RAF WebGL/Canvas rendering loops risk GPU thermal throttling and frame drops on projector laptops.
- **Accessibility Notes**: Reduced motion: not specified in SKILL.md (must add manual override); Contrast: Not specified; requires contrast check on dark surfaces; Keyboard: Preserves visible focus states
- **Bank Security Product Fit**: **fits with care** — Usable if palette is aligned with deep navy/electric teal and animations are kept to fast, subtle micro-interactions.

## 5. Architectural Conflicts & Safe Combinations

### Clashing Patterns (Do NOT Combine)
1. **Dual Smooth-Scroll Engines (`lenis` vs `locomotive-scroll` / `cinematic-gsap-lenis-motion-system`)**:
   - Initializing Lenis alongside Locomotive or native iframe scroll listeners causes violent scroll jitter and event loop contention. As stated in `build-awwwards-quality-sites`: *"Never install or initialize both. Choose exactly one or none."*
2. **Multiple WebGL Canvas Contexts (`threejs` + `cobejs` + `background-grid-webgl` + `shaders-cursor-ripples`)**:
   - Browsers enforce a strict limit of 8-16 active WebGL contexts per page. Spawning multiple full-viewport canvases crashes GPU memory, drops frame rates on laptop displays, and triggers `webglcontextlost`.
3. **Global CSS Reset Clashes (`tailwindcss` CDN vs Hand-crafted Dark CSS)**:
   - `https://cdn.tailwindcss.com` injects Preflight base resets that strip default table borders, button appearances, and heading scales, silently breaking existing tables (`#table-activity`, `#table-receipts`).
4. **Conflicting Typography Paradigms (`book-serif-index` vs `technical-wireframe-info-layout`)**:
   - Mixing literary serif body type with high-tech monospace terminal grids creates visual dissonance and confuses technical evaluation.

### Safe, Synergistic Combinations
- **The Technical Security Stack**: `css-border-gradient` + `progressive-blur` + `beautiful-shadows` + `container-lines` + `number-details`.
  - 100% pure CSS and semantic HTML.
  - Zero external JavaScript, zero CDN calls, zero GPU overhead, 100% offline-ready, perfectly aligned with dark navy and electric teal.
- **The Restrained Motion Stack**: `animation-systems` + `beam-glow-states` + vanilla `animation-on-scroll`.
  - Uses CSS custom properties and lightweight IntersectionObserver.
  - Fully respects `@media (prefers-reduced-motion: reduce)`.
