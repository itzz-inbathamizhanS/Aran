Old side projects and finished plans. They were moved here from the top of the repo during the main branch cleanup, so main shows only what Aran is today. Nothing was deleted, and git history is kept.

| Folder | What it is |
|---|---|
| `iravora-void/` | A separate static website ("Iravora Void"), not part of Aran |
| `site-research/` | Early notes on site design |
| `agent-skills/` | Design skill files that an earlier tool setup used |
| `docs/` | Plans that are now built: persistence lite, SaaS foundation, UI plan, integration diff, design skills inventory |

The full repo as it was before the cleanup is on the branch `Pre_copy_of_main`. To bring one file back: `git checkout Pre_copy_of_main -- <path>`.
