# Workflow

- Work happens locally in `D:\Aran`. Nothing is pushed until you say **save**.
- After every change, update this vault: today's note in `notes/daily` and, for any new branch, [[Branches]].
- **save** means: commit, push to GitHub (cloud), and save a handoff page to Notion.

## Remember everything (standing rule, 2026-10-16)
Project memory lives in this vault. Any new thread should read [[Workflow]], [[Threads]] and [[Branches]] first.
- Every thread, past and future, gets a note in `notes/threads/` and a row in [[Threads]].
- Every artifact is saved under `artifacts/<thread topic>/` by its own title, as Markdown **and** PDF, and listed in [[Artifacts]].
- Every change is logged in today's note in `notes/daily`.
- Learning docs come before any new plan.
