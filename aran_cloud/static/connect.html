Intercept incoming payload before SQL INSERT. Replaces Aadhaar, PAN, Cards and Phone numbers with vault tokens. 

curl -X POST http://127.0.0.1:8100/v1/protect \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Customer Priya Patel with Aadhaar 895760490870 and Card 4532015112830366",
    "customer_ref": "CUST-1001",
    "purpose": "KYC",
    "sink": "kyc-archive"
  }'

Sanitize application logs and telemetry before shipping to Datadog, CloudWatch, or ELK. 

curl -X POST http://127.0.0.1:8100/v1/protect \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "User payment confirmed for 9876543210 (Card 4532015112830366)",
    "purpose": "Service",

  }'

Route AI and customer-care chatbot queries through the AI Gateway. External providers see only placeholders. 

curl -X POST http://127.0.0.1:8100/v1/gateway \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "role": "customer-care",
    "text": "Verify loan application eligibility for customer with Aadhaar 895760490870"
  }'
