## 1. What Aran is

An algebraic data-flow firewall for Indian banks. It finds Aadhaar, PAN, card numbers, UPI IDs and OTPs in APIs, logs and AI tools, replaces them with tokens before they are stored or shared, traces any leak back to the system that leaked it, and supports DPDP-compliant erasure with signed receipts.

The core trick: real Aadhaar and card numbers always pass their check digit (Verhoeff, Luhn); Aran's tokens are built to always fail it, so any scanner can prove whether a number is protected or leaked. On 32,000 real Loghub log lines, false alarms fell from 67,481 to 6 (OTP), 6,086 to 81 (card) and 366 to 4 (Aadhaar), with 0 of 20,000 tokens wrongly flagged.

Built for the BuildX hackathon, team Iravora Void, team ID BX-062. Domain: Banking, Financial Services and FinTech.

## 8. How to run it locally

```
git clone https://github.com/itzz-inbathamizhanS/Aran
cd Aran
docker compose up --build  # console :8000, Aran Cloud :8100, Bank A :9001, Bank B :9002
```

Without Docker: make a venv, `pip install -r app/server/requirements.txt`, then `./scripts/run_demo.sh`. Core and console only: `cd app/server && uvicorn main:app --port 8000`. Windows setup with fixes for common errors: `repo/docs/learning/01-python-and-tools.md`. More options in `repo/README.md` under "Run it".
