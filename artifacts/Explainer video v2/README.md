# Aran - Explainer Video v2 (the full course)

**76.6 minutes in 6 parts, 61 chapters, 1920×1080, 30 fps, English voice-over and subtitles.**

Aran explained from zero for someone with no technical background. Every technical word comes after an everyday example (a waiter for an API, a cloakroom ticket for a token, a lock and key for a check digit, a detective for detection), is drawn as a moving picture while it is spoken, and gets a plain-words card on screen. Real incidents from India and the world show why the problem matters, and a later chapter goes back to each one and says honestly what Aran would and would not have changed. Every chapter ends with a short recap. Subtitles are drawn into the picture, so it can be watched with the sound off.

For a shorter version, see the 24-minute [quick tour (v1)](../Explainer%20video/README.md).

## How it is made

- **Voice:** Kokoro, a small open text-to-speech model, running locally on the CPU (voice af_heart, speed 0.85, about 132 words a minute). No text was sent to an outside service.
- **Pictures:** an SVG player where each frame is drawn from the time alone. A light paper background, ink text and six calm colours; recurring characters who breathe, blink, talk and point; a camera that zooms in on what is being explained; something moving at every moment.
- **Video:** headless Chromium takes one picture per frame and ffmpeg encodes them, then adds the voice.
- **Numbers:** all values on screen are real or computed: the Loghub log lines, the FF1 rounds, the hashes, the Merkle tree and the test results. All identifiers are generated test values with valid check digits, never real people's. Real company names appear only as text in the incident chapters.

[Learn 21](../../docs/learning/21-making-the-explainer-video.md) explains every step and how to change a line. The source is in [source/](source/): `script.txt` (the narration), `tts.py` (voice), `player/engine.js` (the drawing engine), `scenes/` (one file per chapter), `GUIDE.md` (rules for drawing a chapter), `render.js` and `build.py` (frames to the part videos, the full video and the subtitles), `snap.js` and `qa.sh` (checking frames). The voice model files and the generated audio are not in the repo; to rebuild the voice, install `kokoro-onnx` and put `kokoro-v1.0.onnx` and `voices-v1.0.bin` (from the kokoro-onnx project's model-files-v1.0 release) in `source/models/`.
